# Setup Guide — Faizan Ali GitHub Profile

This bundle gives you a fully animated GitHub profile README plus the workflows that auto-generate the dynamic content. Theme is blue (`#00BFFF` / `#1E90FF`) on black (`#000000`). Zero emojis — every icon is a real platform logo from shields.io or skillicons.dev.

---

## File layout

Drop these into your `faizanali2k05/faizanali2k05` profile repo:

```
faizanali2k05/
├── README.md                              ← profile content
└── .github/
    └── workflows/
        ├── snake.yml                       ← contribution snake (blue palette)
```

## What needs the workflows to run first

These reference SVGs that are **generated by the workflows** — the README will show broken images until each workflow runs at least once.

### 1. Snake animation (`snake.yml`)

Already working in your current setup, just with a gold palette. The new workflow regenerates it with a **blue palette** matching the theme.

- Reads from: your contribution graph
- Writes to: `output` branch → `snake-dark.svg`
- README references: `https://raw.githubusercontent.com/faizanali2k05/faizanali2k05/output/snake-dark.svg`
- Runs: every 12 hours + on push + manual trigger

### 2. 3D contribution graph (`profile-3d.yml`)

Generates a stunning 3D isometric view of your contribution calendar.

- Writes to: `profile-3d-contrib/profile-night-rainbow.svg` (committed to main branch)
- README references: `./profile-3d-contrib/profile-night-rainbow.svg`
- Runs: daily at 00:00 UTC + on push + manual trigger
- **First run will fail to commit if the directory doesn't exist** — solution: trigger it manually once via GitHub Actions tab, then it self-heals

### 3. Profile summary cards (`profile-summary.yml`)

Generates three SVG stat cards: profile details, repos per language, most-commit language, and overall stats.

- Writes to: `profile-summary-card-output/tokyonight/*.svg`
- README references the `tokyonight` theme variants (blue accents — fits the theme)
- Runs: daily at 00:00 UTC + on push + manual trigger

## Step-by-step setup

1. **Clone your profile repo locally:**
   ```bash
   git clone https://github.com/faizanali2k05/faizanali2k05.git
   cd faizanali2k05
   ```

2. **Replace `README.md`** with the new one from this bundle.

3. **Add the three workflow files** to `.github/workflows/`. If you already have `snake.yml`, overwrite it — the new one uses the blue palette.

4. **Commit and push:**
   ```bash
   git add .
   git commit -m "feat: redesigned profile with blue/black theme and animated workflows"
   git push origin main
   ```

5. **Trigger each workflow manually once** so the generated SVGs exist:
   - Go to the **Actions** tab of your repo
   - For each workflow (Snake, 3D Contributions, Summary Cards), click **Run workflow** → **Run workflow**
   - Wait ~30 seconds for each to finish

6. **Refresh your profile page** — everything should render.

## Permissions check

Each workflow has `permissions: contents: write` already set, but you also need to enable workflow write access at the repo level:

- Go to **Settings → Actions → General**
- Under **Workflow permissions**, select **Read and write permissions**
- Save

Without this, the 3D contrib and snake workflows will fail when they try to push their generated SVGs.

## Optional upgrade: lowlighter/metrics

If you want a single rich SVG with deeper analytics (languages, followers, achievements, isometric calendar, all in one), add this workflow. It needs a Personal Access Token because it reads more than the default `GITHUB_TOKEN` allows.

1. Create a classic PAT at github.com/settings/tokens with scopes: `public_repo`, `read:user`, `read:org`
2. Add it as a repo secret named `METRICS_TOKEN`
3. Add a workflow file `metrics.yml` (ask me if you want the YAML)
4. Reference the generated `github-metrics.svg` in your README

I left this out of the default bundle because the PAT setup is friction. The current 4 stat cards already cover the same ground.

## Honest caveats

- **`shields.io` badges with niche logos** (`googlemaps`, `briefcase`, `googlescholar`, `googlecalendar`, `aiesec`, `academia`, `langchain`, `handshake`) — shields.io accepts any logo name from simpleicons.org. Most of these exist; if any render as a blank icon, swap the `logo=` value with one from https://simpleicons.org. I picked safe defaults but haven't pixel-verified each one.
- **Streak stats sometimes 502** — the Heroku service that powers `github-readme-streak-stats` has occasional downtime. If that single card breaks for a day, ignore it; it self-heals.
- **Activity graph** flickers if your contribution count is low — this is cosmetic, fixes itself as you commit more.
- **3D contributions** show "no contributions yet" if the repo is brand new. Push some commits first.
